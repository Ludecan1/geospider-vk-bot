# VK-бот: те же уведомления ГЕОСПАЙДЕР, что и Telegram-версия

Отдельный проект рядом с `geospider-bot`. Данные API и район те же; доставка — **личные сообщения сообщества VK**.

## Что нужно в VK

1. **Сообщество** (группа или публичная страница с сообщениями).
2. **Сообщения сообщества**: Управление → Сообщения → включить.
3. **Long Poll**: Управление → Настройки → **Работа с API** (или «Расширенная») → **Long Poll API**:
   - включить Long Poll;
   - в типах событий отметить **«Входящие сообщения»** (`message_new`).
4. **Ключ доступа сообщества** в `.env` как `VK_GROUP_TOKEN`:
   - если есть только право **«Сообщения сообщества»** — бот работает в **режиме опроса** непрочитанных (ответ с задержкой ~2–3 с);
   - для **Long Poll** (быстрее) нужен ключ с доступом к **API управления сообществом** / расширенным API (иначе VK часто вернёт **15** или **27** на `groups.getLongPollServer` — бот попробует **режим опроса** `messages.getConversations`; если и он падает, перевыпустите ключ и проверьте `VK_GROUP_ID`).
5. **ID сообщества** — число из ссылки `club123456` → `123456` или через [id.vk.com](https://id.vk.com/) / `groups.getById` → `VK_GROUP_ID`.

Пользователь **сам** пишет сообществу в личку; после команды «подписка» его `peer_id` сохраняется, дальше приходят оповещения.

## Команды в диалоге с сообществом

| Текст | Действие |
|--------|----------|
| подписка, start, начать, /start | подписка + текущий список станций |
| стоп, отписаться | отписка |
| статус | список станций |
| проверка | проверить изменения вручную |
| помощь | справка |

Кнопки под полем ввода (клавиатура VK) появляются после **подписка**, **помощь** или неизвестной команды. Нажатие кнопки приходит боту как обычный текст («подписка», «статус» и т.д.). Разметка — функция `main_menu_keyboard()` в `bot.py`, отправка — параметр `keyboard` в `messages.send` (см. `vk_api.py`).

## Установка и запуск

1. Один раз: скопируйте `.env.example` → `.env`, заполните `VK_GROUP_TOKEN` и `VK_GROUP_ID` (или задайте их кнопкой **«Настройки VK»** в лаунчере).
2. Дважды щёлкните **`Запустить_VK_бота.bat`**.

### Если в Cursor не видно или «не открывается» `.env`

Файл `.env` в **`.gitignore`**, из‑за этого редактор может **не показывать** его в списке файлов или не открывать по клику.

- В папке `geospider-vk-bot` есть **`.vscode/settings.json`**; если корень в Cursor — вся папка **`nspd-demo`**, то то же включено в **`nspd-demo/.vscode/settings.json`** (`explorer.excludeGitIgnore: false`) — игнорируемые Git’ом файлы снова видны в дереве. Перезагрузите окно (**Developer: Reload Window**), если не применилось.
- Либо откройте вручную: **Файл → Открыть файл…** и укажите путь к `geospider-vk-bot\.env` (или перетащите файл из Проводника Windows в окно редактора).
- Либо не трогайте `.env`: в лаунчере нажмите **«Настройки VK»** — токен и id запишутся в `.env` сами.

Откроется **окно лаунчера** (как у Telegram-бота): **Запуск**, **Стоп**, **Настройки VK**, журнал внизу. При первом запуске bat создаст `.venv` и установит зависимости.

Сам бот после «Запуск» работает в фоне; вывод дублируется в **`data/bot.log`** и подтягивается в окно лаунчера. В начале работы в логе должна появиться строка **`Входящие VK: логика lp+fallback-15-27-netpoll-2026-05-v3`** — если её нет, у вас ещё крутится **старый** процесс: нажмите **«Стоп»**, подождите пару секунд и снова **«Запуск»**.

**Остановка бота:** кнопка **«Стоп»** в лаунчере.

Состояние станций и подписчики лежат в папке **`data/`** (отдельно от Telegram-бота).

### Проверка (`network_check.py`)

Скрипт лежит в папке **`geospider-vk-bot/network_check.py`**. В Cursor откройте его через дерево файлов слева или **Ctrl+P** → введите `network_check`.

Если из **Проводника Windows** двойным щелчком «не открывается» или окно **сразу исчезает** — так бывает у `.py` без консоли: запускайте проверку через **`Проверка_VK.bat`** в той же папке (окно останется открытым, внизу будет `pause`).

Из командной строки:

`cd` в папку `geospider-vk-bot`, затем `.venv\Scripts\python.exe network_check.py`.

## Ограничения VK

- Лимит длины сообщения (~4000 символов); длинные списки при необходимости разбивайте вручную (для ~30 станций обычно помещается).
- Лимиты API VK на частоту `messages.send` — между рассылками в коде добавлена небольшая пауза.
- Если **`network_check`** падал с **`KeyError: 0`** при рабочем ключе: в **API 5.199** ответ **`groups.getById`** приходит как **`{"groups": [...]}`**, а не список — в коде это учтено (`unwrap_groups_get_by_id`).
- Если в логе **`httpx.ConnectError` / `getaddrinfo failed` / WinError 11001** при Long Poll — сбой сети до хоста Long Poll; бот может **перейти на опрос** `messages.getConversations` или задайте **`VK_INCOMING_POLL_ONLY=1`** в `.env`.

## Связь с Telegram-ботом

Это **второй** бот: можно запускать оба (разные токены/сообщества, разные папки `data`). Состояние станций **не синхронизируется** между ними автоматически — при первом запуске каждый снова делает «первый опрос без пушей».

## Ошибка 27 или проверка не проходит

Сообщение вида **`27 Group authorization failed`** значит: VK **не принимает этот ключ** для запроса (часто ключ **отозван**, скопирован с ошибкой, от **другого** сообщества или в `.env` указан не тот `VK_GROUP_ID`).

1. В сообществе: **Управление → Работа с API** — удалите старый ключ и **создайте новый** с правом **«Сообщения сообщества»** (и при необходимости доступом к управлению API для Long Poll).
2. Ключ должен быть **именно «ключ доступа сообщества»** из настроек **этой** группы/страницы, а не пользовательский OAuth-токен и не ключ другого приложения.
3. Вставьте токен в `.env` в **одну** строку `VK_GROUP_TOKEN=...` без кавычек и пробелов в начале.
4. `VK_GROUP_ID` — только цифры из ссылки (`club238890367` → `238890367`). Для **публичной страницы** id может отличаться от «красивого» имени в URL — возьмите числовой id в «Управление» или через [id.vk.com](https://id.vk.com/).
5. Раньше **переменные среды Windows** с именем `VK_GROUP_TOKEN` могли перекрывать значение из файла. Сейчас бот всегда читает `.env` из папки с `config.py` с приоритетом над средой; если сомневаетесь — удалите `VK_GROUP_TOKEN` / `VK_GROUP_ID` из «переменных среды» пользователя/системы.
6. Запустите проверку: **`Проверка_VK.bat`** или в папке бота **`python network_check.py`** — в начале будет путь к используемому `.env`.

Если лаунчер пишет, что проверка не прошла, можно согласиться **«Запустить всё равно»** — в `data/bot.log` появится та же диагностика, но без рабочего ключа бот не сможет ни читать, ни слать сообщения.
